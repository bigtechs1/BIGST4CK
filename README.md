## 📌 Features

- **Interactive Messages** – Buttons, lists, carousels, and rich cards.
- **Group Management** – Kick, promote, demote, mute, warn, and more.
- **Downloaders** – TikTok, Instagram, Facebook, YouTube (audio & video).
- **AI Features** – Chatbot, image generation (AI).
- **Security** – Antilink, antimention, anticall, antidelete.
- **Auto Features** – Autoread, autotyping, autostatus.
- **Welcome & Goodbye** – Customisable with images and group description.
- **Server Store** – Pterodactyl server plans with images.
- **System Monitoring** – Ping, uptime, RAM, CPU usage.
- **Self-Update** – Update bot directly from GitHub.

## 📋 Prerequisites

- **Node.js** ≥ 18.0.0
- **npm** or **yarn**
- **ffmpeg** (for media processing)
- **Git** (for cloning)
